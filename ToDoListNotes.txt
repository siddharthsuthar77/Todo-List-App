getting local storage for todolist :
>> let todos = JSON.parse(localStorage.getItem("ToDo-List"));

data stored in the browser's localStorage with the key "ToDo-List".
Eg: "ToDo-List" : '[{"name":"Study JavaScript","status":"pending"}]'
Data from localStorage is returned as a string.

JSON.parse() converts a JSON string into a real JavaScript value/object.

For example:
let data = '[{"name":"Study JavaScript","status":"pending"}]';

After: JSON.parse(data);

It becomes a real JavaScript array containing an object:
[
    {
        name: "Study JavaScript",
        status: "pending"
    }
]
Now JavaScript can easily work with the array and its objects.
